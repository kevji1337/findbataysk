# 🤖 FindBataysk Bot

Telegram бот для реферальной программы и управления рекламой в канале.

## 🚀 Быстрый старт

### 1. Настройка окружения

```bash
# Создать виртуальное окружение
python -m venv .venv
# Активировать (Windows)
.venv\Scripts\activate
# Активировать (Linux/Mac)
source .venv/bin/activate

# Установить зависимости для разработки
make install
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Заполни `.env`:
- `BOT_TOKEN` — от @BotFather
- `CHANNEL_ID` — ID канала (начинается с -100)
- `ADMIN_IDS` — ID админов через запятую
- `DATABASE_URL` — ссылка на Postgres (Supabase или локальный)
- `REDIS_URL` — ссылка на Redis

### 3. Настройка Telegram

> ❗️ **ВАЖНО:** Бот **ОБЯЗАН** быть администратором канала!
> Права: 
> - Добавление пользователей (Invite Users)
> - Управление ссылками (Manage Invite Links)
> Без этого реферальная система работать не будет.

### 4. Запуск в Docker (рекомендуется)

```bash
# Запустить всё (Бот + Redis)
docker compose up -d

# Смотреть логи
docker compose logs -f bot
```

### 4. Локальная разработка

Если база данных запущена отдельно (например, в Supabase или локально в Docker):

```bash
# Применить миграции
alembic upgrade head

# Запустить бота
python -m bot.main
```

## 🔧 Функционал

### Для пользователей:
- 🔗 **Реферальная программа** — персональные ссылки, статистика
- 🎁 **Подарки** — автоматический подсчёт наград (1 мишка за 5 приглашённых)
- 📢 **Заявки на рекламу** — подача, отслеживание статуса
- 📞 **Связь с админом**

### Для админов:
- 📊 **Топ рефереров** — лидерборд
- 📋 **Модерация заявок** — одобрение/отклонение в один клик
- 📣 **Рассылки** — фоновая рассылка с защитой от блокировок

## ⚙️ Полезные команды (Makefile)

```bash
make install        # Установить зависимости
make run            # Запустить бота локально
make clean          # Очистить кэш
make test-refs      # Добавить тестовых рефералов
```

## 🔐 Безопасность

1. **Секреты**: Никогда не коммить `.env`.
2. **Админка**: Доступ защищён на уровне роутера.
3. **Бэкапы**: Регулярно делай дамп базы данных.
